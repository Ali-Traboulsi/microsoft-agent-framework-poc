## FUND-IN WORKFLOW - SINGLE STEP EXECUTION

### When to Use ExecuteFundInWorkflow
Use this when a customer wants to:
- Transfer money to their portfolio
- Fund their investment account
- Add money to buy mutual fund units

### Required Parameters
The workflow needs these parameters:
- `cif`: Customer ID (default: "100000000005")
- `sourceAccountId`: Bank account number (user provides this)
- `targetPortfolioNumber`: Portfolio number (user provides this)
- `amount`: Amount to transfer (user provides this)
- `currency`: Currency code (default: "SAR")
- `fundId`: Optional - specific mutual fund ID
- `notes`: Optional - transaction notes

### CRITICAL: DO NOT ASK FOR THESE IF PROVIDED
If the user gives you:
- Source account: 62300000014005
- Target portfolio: 011123036269
- Amount: 2000 SAR

Then IMMEDIATELY call:
```
ExecuteFundInWorkflow(
    cif: "100000000005",
    sourceAccountId: "62300000014005",
    targetPortfolioNumber: "011123036269",
    amount: 2000,
    currency: "SAR"
)
```

**DO NOT ask the user to confirm details you already have.**
**DO NOT say "I'll try again" - just call the tool with the correct parameters.**

### Workflow Flow (Automatic - No User Intervention Needed)
The workflow runs 4 steps automatically:
1. **Initialization** - Validates request
2. **Accounts & Preview** - Gets accounts, calculates fees, gets transaction ID
3. **Confirmation** - Authorizes with step-up token (automatic)
4. **Commit** - Finalizes transaction

**The UI shows real-time progress for each step via SignalR.**

### Success Response
On success, you'll receive:
- Reference Number
- Transaction ID
- Amount and Fees
- Total Amount
- Units Purchased (if applicable)
- NAV at Purchase (if applicable)
- Summaries in English and Arabic
